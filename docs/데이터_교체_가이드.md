# 공간 데이터(spaces.json) 교체·업데이트 가이드

파일 위치: `public/data/spaces.json` — 사이트의 모든 공간 목록·검색·카테고리·지역 페이지가 이 파일 하나에서 나옵니다. 교체 후 `npm run build`(또는 GitHub push)하면 라우트·사이트맵까지 자동으로 다시 생성됩니다.

## 1. 구조

```json
{
  "meta":  { "defaultGrade": "D", "generated": "2026-07-12", "source": "..." },
  "kinds": [ { "c1": "파티·모임", "c2": "파티룸", "c3": "올인원 파티룸", "form": "단독 대관",
               "tags": ["생일","모임"], "price": "시간당 2-8만원", "checks": ["인원","노래방","주차"] } ],
  "descs": [ "설명 문구 1", "설명 문구 2" ],
  "spaces":[ { "id": "PVIT-10001", "n": "업체명", "s": "서울", "g": "강남구",
               "q": "지도 검색어", "k": 0, "d": 0 } ]
}
```

- `k` = `kinds` 배열의 순번, `d` = `descs` 배열의 순번 (중복 제거용)
- `q` = 지도 검색어. 네이버·구글 지도 URL 은 이 값으로 사이트에서 자동 생성됩니다. **정확한 상호 + 지역**일수록 지도 링크가 정확해집니다.

## 2. 검증된 업체 정보가 생기면 — 공간 객체에 필드만 추가

| 필드 | 효과 |
|---|---|
| `"grade": "A"` | '호스트 인증' 초록 뱃지, 검색 상단, **검색엔진 색인 + 사이트맵 + LocalBusiness 구조화 데이터 자동 ON** |
| `"grade": "B"` | '공식채널 검증' 뱃지, 위와 동일 |
| `"tel": "02-1234-5678"` | 카드·상세에 전화 버튼 |
| `"img": "https://.../photo.jpg"` | 대표 사진 (카드·상세·OG) |
| `"reserve": "https://booking.naver.com/..."` | 상세에 예약 페이지 버튼 |
| `"home": "https://..."` | 공식 홈페이지 버튼 |
| `"insta": "https://instagram.com/..."` | 인스타그램 버튼 |
| `"naverUrl": "https://map.naver.com/p/entry/place/123"` | 검색 URL 대신 **정확한 장소 URL** 로 연결 |
| `"googleUrl": "https://maps.app.goo.gl/..."` | 구글 장소 URL |
| `"desc": "이 공간만의 소개문"` | `descs` 공통 문구 대신 개별 소개 |

예시:
```json
{ "id": "PVIT-10001", "n": "스파 더 프라이빗 강남점", "s": "서울", "g": "강남구",
  "q": "스파 더 프라이빗 강남점", "k": 1, "d": 0,
  "grade": "A", "tel": "02-1234-5678", "img": "https://cdn.example.com/spa-gangnam.jpg",
  "reserve": "https://booking.naver.com/booking/12/bizes/123456",
  "naverUrl": "https://map.naver.com/p/entry/place/1234567890",
  "desc": "강남역 4번 출구 도보 3분. 히노끼탕·건식 사우나·샤워실이 룸 안에 있는 2인 전용 독채형 룸 4개 운영." }
```

## 3. 새 카테고리 추가 (룸식당·독채·촬영 등)

`kinds` 에 객체를 추가하면 됩니다. `c1`(대분류)이 기존 7개와 다르면 사이트가 자동으로 새 카테고리로 인식합니다. 아이콘·색·영문 슬러그를 지정하려면 `src/lib/data.js` 의 `CAT1`, `KIND_SLUG` 에 한 줄씩 추가하고, 랜딩 문구는 `src/content/categories.js` 에 추가하세요(없으면 기본 문구로 동작).

## 4. 엑셀에서 다시 내보내기

원본 엑셀(`PVIT_프빗_플랫폼_등록용_DB`)의 `01_프빗 등록용 DB` 시트 기준으로 변환하던 스크립트 로직은 다음과 같습니다(파이썬, 참고용):

```python
import pandas as pd, json
df = pd.read_excel("DB.xlsx", sheet_name="01_프빗 등록용 DB")
kmeta = df.groupby(["프빗 대분류","프빗 중분류","프빗 소분류","공간 형태","추천 이용목적 태그","이용 금액대"]).size().reset_index()
kinds, kidx = [], {}
for _, r in kmeta.iterrows():
    kidx[r["프빗 소분류"]] = len(kinds)
    kinds.append({"c1": r["프빗 대분류"], "c2": r["프빗 중분류"], "c3": r["프빗 소분류"], "form": r["공간 형태"],
                  "tags": r["추천 이용목적 태그"].split(","), "price": r["이용 금액대"], "checks": []})
descs = sorted(df["상세 서비스 설명"].unique().tolist()); didx = {d:i for i,d in enumerate(descs)}
spaces = []
for _, r in df.iterrows():
    s = {"id": r["PVIT ID"], "n": r["업체명"], "s": r["시도"], "g": r["시군구"], "q": r["지도 검색어"],
         "k": kidx[r["프빗 소분류"]], "d": didx[r["상세 서비스 설명"]]}
    for col, key in [("전화번호","tel"),("대표 이미지 URL","img"),("네이버예약/외부예약 URL","reserve"),("공식 홈페이지 URL","home")]:
        if pd.notna(r[col]) and str(r[col]).strip(): s[key] = str(r[col]).strip()
    g = str(r["실존 검증등급"])[:1]
    if g in "ABC": s["grade"] = g
    spaces.append(s)
json.dump({"meta": {"defaultGrade": "D"}, "kinds": kinds, "descs": descs, "spaces": spaces},
          open("public/data/spaces.json","w",encoding="utf-8"), ensure_ascii=False, separators=(",",":"))
```

## 5. 노출 정책

`src/lib/data.js` → `CONFIG.VERIFY_MODE`
- `"open"` (현재): 전체 노출, 미검증은 '정보 확인 중' 뱃지 + 안내 배너
- `"strict"`: A·B 등급만 노출 — 검증된 공간이 충분히 쌓였을 때 전환
