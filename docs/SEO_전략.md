# 프빗 SEO 전략

검색에서 '프라이빗 공간'을 찾는 사람이 프빗을 먼저 만나게 하는 것이 목표입니다. 네이버와 구글 둘 다 봅니다. 한국 사용자는 네이버 비중이 크고, 네이버는 자바스크립트로만 그려진 페이지를 잘 읽지 못하므로 **사전 렌더링(SSR)** 을 기본으로 깔았습니다.

## 1. 구조적 SEO — 이미 적용된 것

| 항목 | 내용 |
|---|---|
| URL 라우팅 | 모든 페이지가 고유 URL (`/category/party`, `/region/seoul`, `/guide/...`, `/space/PVIT-xxxx`). 영문 슬러그로 짧고 공유하기 쉬움 |
| 사전 렌더링 | 빌드 시 76개 라우트를 완성된 HTML 로 생성 → 크롤러가 JS 없이 본문·링크·메타를 읽음 (테스트: JS 끄고도 가이드·지역 목록 렌더 확인) |
| 메타 태그 | 페이지별 `title`(60자 내외) · `description`(155자 내외) · `canonical` · Open Graph · Twitter Card |
| 구조화 데이터 | Organization, WebSite(SearchAction), BreadcrumbList(전 페이지), ItemList(카테고리·지역·가이드), FAQPage(FAQ·카테고리·호스트), Article(가이드), HowTo(입점 절차), LocalBusiness(검증 공간만) |
| 사이트맵 | `sitemap.xml` 자동 생성(63 URL, lastmod 포함), `robots.txt` 에 연결 |
| 내부 링크 | 푸터에 카테고리 7 + 지역 8 + 호스트 5 링크, 카테고리↔지역↔가이드↔상세 상호 링크, 브레드크럼 |
| 성능 | CSS 16KB·JS 133KB(gzip), 이미지 lazy, 폰트 preconnect, `_headers` 로 자산 1년 캐시 |
| 모바일 | 반응형, 하단 고정 CTA, viewport 설정 |
| OG 이미지 | `public/og-image.png` (1200×630) — 카톡·인스타 공유 시 표시 |

### 색인 정책 (중요)
- **색인 O**: 홈, 공간찾기, 카테고리 17개, 지역 15개, 가이드 14편, 호스트 안내·운영 가이드, FAQ, 커뮤니티
- **색인 X (noindex)**: 미검증(D등급) 공간 상세 3,000개, 필터 조합 검색 결과(`/search?...`), 호스트 센터·신청서, 약관
- 이유: 설명문 60개가 50번씩 반복되는 미검증 데이터를 그대로 색인시키면 "얇은 중복 페이지"로 도메인 전체 평가가 떨어집니다. 검증(A/B)으로 바뀐 공간은 자동으로 색인·사이트맵·LocalBusiness 가 켜집니다. `CONFIG.INDEX_UNVERIFIED` 로 바꿀 수 있습니다.

## 2. 키워드 지도

### 핵심 (브랜드·정의)
`프라이빗 공간` · `프라이빗 공간 대여` · `우리끼리 공간` · `독립 공간 대관` · `단독 대관` · `프빗` · `PVIT`
→ 홈, `/about`, 가이드 "프라이빗 공간이란?"

### 카테고리 (거래 의도 높음)
| 키워드 군 | 대표 페이지 |
|---|---|
| 파티룸 추천 · 파티룸 예약 · 생일파티 장소 · 송년회 장소 · 브라이덜샤워 장소 | `/category/party`, `/category/party-room`, 가이드 2편 |
| 프라이빗 사우나 · 가족탕 · 커플 스파 · 히노끼탕 | `/category/spa`, `/category/private-sauna`, 가이드 |
| 1인 세신샵 · 프라이빗 세신 · 세신 가격 | `/category/sesin-spa`, 가이드 |
| 프라이빗 시네마 · 영화룸 데이트 · OTT 룸 · 사운드룸 | `/category/cinema-game`, `/category/cinema-room`, 가이드 |
| 키즈 워터룸 · 키즈 파티룸 · 아이 생일파티 장소 | `/category/kids`, `/category/kids-water-room`, 가이드 |
| 포커스룸 · 1인 사무실 시간제 · 화상회의 공간 · 면접 장소 | `/category/work`, `/category/focus-room`, 가이드 |

| 룸식당 · 룸 있는 식당 · 프라이빗 다이닝 (확장 예정 카테고리) | 가이드로 선점 |
| 독채 펜션 · 독채 풀빌라 · 가족 독채 숙소 (확장 예정) | 가이드로 선점 |

### 지역 롱테일
`강남 파티룸` `홍대 파티룸` `성수 프라이빗` `잠실 키즈 워터룸` `부산 프라이빗 사우나` `제주 독채` …
→ `/region/{시도}` 15개 + 지역 가이드. 다음 단계로 `/region/{시도}/{구}` 78개와 `지역×유형` 조합 페이지(예: 강남 파티룸)를 추가하면 롱테일이 크게 늘어납니다. 데이터에 실제 업체가 쌓인 뒤 여는 것을 권합니다(지금 열면 얇은 페이지가 됩니다).

### 호스트 (B2B)
`파티룸 창업` `공간대여 창업` `무인 공간 운영` `공간대여 플랫폼 입점` `파티룸 운영 노하우`
→ `/host`, `/host/guide`, 가이드 "프라이빗 공간 운영의 기본"

## 3. 콘텐츠 — 지금 들어간 것과 다음 것

가이드 14편(각 1,500~2,500자, 사람이 쓴 톤, 표·체크리스트 포함)이 `src/content/guides-a.js`, `guides-b.js` 에 있습니다. 글을 추가하려면 같은 형식으로 객체 하나를 더 넣고 `npm run build` 하면 라우트·사이트맵·JSON-LD 가 자동 생성됩니다.

다음 글 후보 (검색량·경쟁 고려 순):
1. 송년회·연말 모임 장소 — 10명·20명·30명 규모별 (시즌 키워드, 10월 중 발행)
2. 상견례 룸식당 고르는 법 (룸식당 카테고리 오픈 대비)
3. 셀프스튜디오·촬영 공간 대관 — 프라이빗 촬영의 기준
4. 반려동물 동반 프라이빗 공간 — 애견 파티룸·독채
5. 경기·인천 지역별 가이드 (서울 편과 같은 형식)
6. 부산·제주 여행 겸 프라이빗 공간 코스
7. 프라이빗 공간 예약 전 취소·환불 정책 읽는 법
8. 호스트: 사진 촬영 가이드 (휴대폰으로 공간 사진 잘 찍는 법)

## 4. 등록 — 사이트를 올린 뒤 꼭 할 것

### 네이버 서치어드바이저 (searchadvisor.naver.com)
1. 웹마스터 도구 → 사이트 등록 → `https://pvit.pages.dev` (또는 연결한 도메인)
2. 소유 확인: "HTML 태그" 방식 → 발급된 `content` 값을 `index.html` 의 `<meta name="naver-site-verification">` 에 넣고 다시 배포
3. 요청 → 사이트맵 제출: `https://도메인/sitemap.xml`
4. 요청 → RSS 제출은 없음(해당 없음). 웹 페이지 수집 요청으로 홈·카테고리·가이드 URL 을 수동 요청
5. 검증 → robots.txt 확인

### 구글 서치콘솔 (search.google.com/search-console)
1. 속성 추가 → URL 접두어 → 사이트 주소
2. 소유 확인: HTML 태그 → `<meta name="google-site-verification">` 에 입력 후 배포
3. Sitemaps → `sitemap.xml` 제출
4. URL 검사로 홈·카테고리 몇 개 '색인 생성 요청'

### 네이버 플레이스·블로그 연동 (선택)
- 네이버 블로그/포스트에 가이드 요약 + 프빗 링크를 올리면 네이버 검색 노출이 빨라집니다.
- 호스트 인증 공간이 쌓이면 각 공간의 네이버 플레이스 '웹사이트' 란에 프빗 상세 URL 을 넣도록 안내 (역링크).

## 5. 도메인 연결 시

1. `src/lib/seo.jsx` → `SITE.url` 을 새 도메인으로
2. Cloudflare Pages 빌드 환경변수 `SITE_URL=https://pvit.kr` 설정 (사이트맵·robots 에 반영)
3. 서치어드바이저·서치콘솔에 새 도메인 속성 추가, 사이트맵 재제출
4. `pages.dev` 주소는 Cloudflare 에서 새 도메인으로 301 리다이렉트 설정

## 6. 측정

- 서치콘솔 '실적' 에서 쿼리별 노출·클릭 — 카테고리·가이드 페이지가 어떤 검색어로 들어오는지 2~4주 후 확인
- 서치어드바이저 '리포트' 에서 수집 현황·검색 노출
- Cloudflare Web Analytics(무료, 스크립트 한 줄) 를 `index.html` 에 추가하면 페이지별 방문을 볼 수 있습니다
